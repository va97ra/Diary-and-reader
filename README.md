# Дневник

Кроссплатформенная авторская студия на Flutter и Dart для Windows, Android,
iOS и Web. Поддерживает русский и английский языки, проекты книг, главы и
сцены, форматированный текст, адаптивные A4-страницы, читалку и экспорт в
EPUB, PDF и DOCX.

На нативных платформах рукопись автоматически сохраняется атомарно в каталоге
данных приложения. Две вращающиеся резервные копии и журнал незавершённой
записи позволяют восстановиться после повреждения файла или внезапного
завершения приложения. При первом запуске прежние локальные данные мигрируют
автоматически; Web продолжает использовать хранилище браузера.

## Архитектура

- `lib/app` — сборка приложения и маршрутизация верхнего уровня.
- `lib/core` — тема и локализованные строки.
- `lib/features/books/domain` — модель книги и интерфейс репозитория.
- `lib/features/books/data` — нативное файловое хранилище, миграции и экспорт.
- `lib/features/books/application` — состояние авторской студии и сценарии.
- `lib/features/books/presentation` — адаптивный редактор и читалка.
- `lib/features/diary` — совместимость и миграция данных ранней версии.

UI зависит от контроллера, контроллер — только от интерфейса репозитория. Формат
хранения можно заменить на SQLite, шифрованное хранилище или сервер без
переписывания экранов.

## Проверка

```powershell
flutter analyze
flutter test
flutter build web --release
flutter build windows --release
flutter build apk --debug
```

Тот же набор проверок автоматически запускается в GitHub Actions для ветки
`main` и каждого pull request. Версия Flutter закреплена на `3.44.6`, чтобы
локальная и автоматическая сборки давали одинаковый результат.

## Идентификаторы приложения

- Android package / iOS bundle: `app.dnevnik`.
- Отображаемое имя: `Дневник`.
- Версия приложения: `1.0.0+1`.

Точки входа для Web, Android, iOS и Windows созданы стандартными средствами
Flutter. Для сборки конкретной платформы нужны её системные инструменты.
