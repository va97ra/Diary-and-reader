# Правила проекта «Литерия»

## Карта кода — обязательно

1. **Перед началом любой работы** в проекте прочитать `docs/CODE_MAP.md` и
   искать нужное по ней, а строки — в `docs/CODE_SYMBOLS.md`, а не по всему
   коду.
2. **После каждой правки кода** запустить `dart run tool/code_map.dart`
   (обновляет `docs/CODE_SYMBOLS.md` с номерами строк) и поправить
   `docs/CODE_MAP.md`: новые или удалённые файлы, переезд логики, новые общие
   помощники, изменившиеся сценарии; дописать строку в «Журнал правок карты».
3. Если карта разошлась с кодом — сначала поправить карту.

## Прочее

- Общайся с пользователем по-русски.
- Без дублирования кода; устаревший и мёртвый код удалять в той же правке.
- Проверка перед сдачей: `dart format lib test tool`, `flutter analyze`,
  `flutter test`.
- Версия: `pubspec.yaml` и `lib/app/literia_version.dart` меняются вместе.
