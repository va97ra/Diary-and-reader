# План развития авторской студии

## Принципы

1. Книга хранится как семантический документ, а не как набор экранных страниц.
2. Авторское оформление, печатная верстка и настройки читалки независимы.
3. Все данные доступны офлайн и имеют переносимую резервную копию.
4. Каждый экспорт реализуется отдельным адаптером поверх общей модели книги.
5. Большие изменения вводятся небольшими мигрируемыми слоями с тестами.

## Этапы

### 1. Модель книжного проекта

- Проекты книг и издательские метаданные.
- Плоское упорядоченное дерево: тома/части, главы и сцены.
- Семантическое содержимое раздела без сохраненных экранных страниц.
- Миграция существующих дневниковых записей в главы одной книги.

### 2. Адаптивная авторская студия

- Библиотека проектов.
- Навигатор частей, глав и сцен.
- Центральный редактор и панель свойств.
- Телефон: одна рабочая область и нижняя навигация.
- Планшет/компьютер: сворачиваемые боковые панели.

### 3. Редактор и представление страниц

- [x] Стили абзацев, заголовков, цитат, эпиграфов и разделителей сцен.
- Шрифты, размеры, интервалы, отступы и поля.
- [x] Один лист, книжный разворот и непрерывный режим.
- Страницы вычисляются для просмотра и не изменяют исходный документ.

### 4. Читалка

- [x] Оглавление и сохраняемый прогресс по разделам.
- [x] Поиск по всей книге, закладки и заметки.
- Выделения текста и экспорт читательских аннотаций.
- [x] Светлая, темная и сепия-темы.
- [x] Постраничный и непрерывный режимы, одна страница или разворот.
- [x] Независимые настройки шрифта, интервалов и ширины текста читателя.

### 5. Импорт и экспорт

- EPUB 3.3 как основной электронный формат.
- PDF для печати и фиксированной верстки.
- DOCX для редакторов и издательств.
- FB2/FB2.ZIP, HTML, Markdown и TXT.
- Предварительный просмотр и валидация результата.

### 6. Профессиональные инструменты

- Автосохранение, снимки версий и восстановление.
- Цели, статистика, статусы глав и издательская проверка.
- Персонажи, места, заметки, сюжетные линии и хронология.
- Опциональная синхронизация после стабилизации локальной версии.
